# Первоисточники: нормативные документы

Здесь лежат документы, по которым проверяются факты карточек: постановления администрации,
административные регламенты муниципальных услуг, распоряжения.

- Пакет административных регламентов по всем муниципальным услугам передаёт администрация
  (Шаг 2, в работе) — раскладываем по файлам, имя файла = вид услуги.
- Документ здесь — **доказательство факта**, а не то, что бот читает в рантайме: факт переносим в
  карточку `faq/`, а в карточке указываем `источник:` на файл.
- Свежесть документа проверяем метаданными файла, а не датой публикации на сайте:
  `unzip -p файл.docx docProps/core.xml`; для `.doc` — свойства файла (`exiftool`).
- Публичные документы кладём файлами; непубличные — только ссылкой и реквизитами, файл в публичный
  репозиторий не попадает.
