# admtavda-ai-assistant

ИИ-ассистент администрации Тавды: бот в MAX, отвечает жителям по базе знаний (режим работы, контакты, справки), умеет рассказать погоду и новости.

## Статус 

Учебный проект DevOps-курса. В разработке (Шаг 0 — каркас)

## Стек

- Python 3.14
- MAX API (бот)
- GigaChat API (LLM, РФ)

## Структура

- `src/` — код бота
- `.env` — секреты (не в git!)
